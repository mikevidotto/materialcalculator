Changes to the Ontario Building Code

The Ontario Building Code has been changed.

Sheds up to 15m² or 161 sq.ft can now be built without a permit when applicable.

This is as long as the shed:

  • Is not more than one storey in height
  • Is not attached to any other structure
  • Is only used for storage purposes related to the house on the property
  • Does not have plumbing
